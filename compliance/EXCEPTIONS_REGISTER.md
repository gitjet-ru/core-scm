# Compliance Exceptions Register (core-scm)

Use this register only for temporary, approved exceptions to the strict permissive policy.

## Fields

- Date opened (YYYY-MM-DD)
- Owner (team/person)
- Component/package
- Why exception is needed
- Risk assessment
- Mitigation
- Expiration date
- Approval reference
- Date closed

## Active Exceptions

No active exceptions.
